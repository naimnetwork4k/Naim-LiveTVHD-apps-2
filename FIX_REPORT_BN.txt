Naim LiveTVHD - ফিক্স রিপোর্ট

যা পরিবর্তন করা হয়েছে:
1. Android Capacitor APK-তে NativeVideoPlayer JavaScript bridge যুক্ত করা হয়েছে।
2. Android APK-তে HLS/M3U8, DASH/MPD, MPEG-TS এবং RTSP-এর জন্য Media3 Native Player চালুর চেষ্টা হবে।
3. Native bridge না থাকলে ওয়েবসাইটের আগের inline HTML player চালু থাকবে।
4. GitHub Actions workflow-তে বিদ্যমান capacitor.config.json ব্যবহার করা হয়েছে; অপ্রয়োজনীয় cap init ধাপ বাদ।
5. JPG লোগোকে প্রকৃত PNG-তে রূপান্তর করে Android icon/splash resource তৈরি করা হয়।
6. HTML-এর JavaScript syntax এবং JSON config পরীক্ষা করা হয়েছে।

যা পরীক্ষা করা হয়নি:
- GitHub Actions-এ বাস্তব Android APK build এই পরিবেশে চালানো হয়নি।
- কোনো IPTV সার্ভারের URL/Token/CORS/DRM live যাচাই করা হয়নি।
- RTMP/FLV/SmoothStreaming সব ডিভাইসে চলবে—এমন নিশ্চয়তা নেই।

ব্যবহার:
1. ZIP extract করে GitHub repository-তে ফাইলগুলো upload/replace করুন।
2. main বা master branch-এ commit/push করুন।
3. GitHub > Actions থেকে "Build Android APK with Custom Logo" workflow সফল হয়েছে কি না দেখুন।
4. সফল হলে Artifacts থেকে APK download করে Android-এ install করে পরীক্ষা করুন।
5. APK build সফল হলেও কোনো নির্দিষ্ট stream না চললে তার server-side access, token, codec বা DRM সমস্যা থাকতে পারে।
